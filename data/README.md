# 教学视频数据约定（本仓库不包含视频原文件）

当前实际已有：**静止装甲板视频、装甲板原地旋转视频**。这不是公开再分发授权。先由主力确认版权、机位、相机型号、分辨率及是否含内部信息，再通过受控渠道发给新人。建议视频用网盘/内网共享，不放进 Git 仓库（视频体积大且可能含敏感信息）。

## 主力需补的最小元数据

| 字段 | 示例/说明 |
|---|---|
| video_id | `static_001`（建议代号，不含个人姓名） |
| scene | static / spin |
| camera_model | 尚待记录 |
| resolution | 视频实际宽×高 |
| fps | 从文件实际读取；不是算法实际 FPS |
| crop_or_resize | 是否曾裁切/缩放 |
| intrinsics_id | 未确认 / 已匹配的标定 ID |
| ground_truth | 无 / 有距离测量 / 有人工标注 |
| license | 仅队内使用 / 可公开，需确认 |

**W4～W5** 可直接使用视频学读取和候选检测；**W6～W8** 如果内参无法核实，优先用合成参数和手工角点验证 PnP。不要虚构真实距离误差。

请将实际视频元数据记录在 `data/video_manifest.csv`；该 CSV 仅包含信息，不包含视频文件。
