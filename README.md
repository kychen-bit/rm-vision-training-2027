# RoboMaster 2027 视觉组 · 自瞄方向新人培养计划

> **状态**：可直接使用的第 1 版培训仓库（2026-11-16）。先运行两周、观察负担，再微调后续任务；不是一成不变的竞赛承诺。
>
> **受众**：4 名大一新生（尚不确定能否独立编码）；3 名现有主力负责有限答疑和审核。
>
> **制度**：大一以梯队为主，能力突出的成员可提前承担开发；是否成为主力以实际贡献、队内制度及比赛资格为准。

## 从这里开始

- **新人**：先读本页 → 找到对应周次的 `知识.md`（了解为什么学）→ `任务.md`（知道做什么、怎样验收）→ 提交作业。
- **本周直接入口**：[第 2 周任务](weeks/week02/任务.md) · [systemd 完整讲解](weeks/week02/知识01_systemd服务.md) · [线代与坐标变换](weeks/week02/知识02_线性代数与坐标变换.md)
- **负责人**：先看 [培养与考核规则](management/培养与考核规则.md)、[主力最低投入流程](management/主力周任务工作流.md)、[GitHub 组织搭建](management/GitHub组织与仓库搭建.md)。
- **已准备视频**：只有静止装甲板和原地旋转装甲板；参见 [数据说明](data/README.md)。视频本身尚未收录，需检查版权与内部许可。

## 我们要培养的不是“教程复印机”

**目标**：学会从任务拆解、查文档、编译、调试、测试、说明，到能够独立开发简化版 **MiniAutoAim（视频输入 → 角点/候选检测 → PnP → 可视化）**。

最低项目标准允许**手工标注角点**进入 PnP 流程；自动装甲板检测是进阶项。本阶段不要求 EKF、反小陀螺、弹道控制或准确率达竞赛级水平。

> 视频与相机标定参数是否匹配尚未确认。前期用**合成内参/人工标注**学习；未经校验的参数不能作为真实测距准确性的证据。

### 三个评价节点

- **W03 能力摸底**：独立写程序、Git/CMake、解决问题的基础，调整 W04～W06 难度。
- **W06 阶段检查**：OpenCV、小任务推进和主动反馈；尽量在此之前确定需要辅导的人。
- **W10 MiniAutoAim 考核**：可运行、可解释、可测试、可复现；考核成绩只是留队判断证据之一。
- **W11～W14** 工程衔接：读懂旧项目、离线运行、完成小 PR、试探专精方向，不承诺必然进入赛季核心研发。

## 一个正常的任务周怎样运转？

1. 周一：负责人发布本周 `知识.md` + `任务.md`（以此目录为准）。
2. 周三/周四：大家在 Issue 或群中回报“当前进度/卡点”，主力只解答共性问题。
3. 周日 23:59：个人分支 / PR 提交，附 README、截图/视频、问题记录。
4. 周一～周二：主力按抽查表快速打分并评论；未按要求完成者说明补交计划。

**不主张每周集体讲课。** 对同一问题统一写 FAQ；不为每个人重复讲解。

## 成绩与留队原则

参照 [评分表](management/每周评分表.md)：完成与正确性 40%、理解 25%、自主排错 20%、提交与规范 15%。

能力分和投入态度分开：不按一周任务失败就自动淘汰。累计无说明缺交/失联等先沟通，再由负责人按队规综合决定；**不设固定淘汰人数**。主动求助且有实际尝试的新人可以补交。
