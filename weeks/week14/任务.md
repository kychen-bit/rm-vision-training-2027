# W14 每周任务：方向试探与培养复盘

- **日期**：2027-02-08 ～ 2027-02-14
- **截止**：2027-02-14（周日）23:59，中国标准时间 UTC+8
- **投入预算**：7 小时/人；方向调研 2h／小任务 3h／总结 2h
- **完成形式**：四人各自独立完成；允许查文档和使用 AI，但必须能解释自己的代码。
- **先读**：[知识.md](知识.md)；W02 另有专题知识文档。

## 本周要达成什么能力？

体验不同方向的任务类型，按兴趣、能力与队伍需求制定后续专精计划。

## 完成路径（按顺序做）

1. 阅读三个方向的简短任务简介，每人申报第一/第二志愿。
2. 任选 1 项 3 小时低风险试探题（方向见 `任务.md`），不以竞赛级精度为目标。
3. 提交 1 页复盘，包括已掌握、最难问题、希望承担的任务。
4. 三名主力只需基于材料反馈下一阶段推荐路线。

## 基础必做（以可复现为准）

- [ ] 试探题结果或完整排错记录
- [ ] 主/备方向志愿
- [ ] 后续四周个人学习目标
- [ ] 最终阶段复盘

## 选做挑战（不作为留队硬门槛）

- 给一名学弟学妹讲清一个过去自己不懂的知识点

## 交付方式与证据

1. 在本人分支或个人提交目录中上传源码、CMakeLists、README 与测试记录；不要上传 `build/`、系统文件、未授权比赛视频、设备密钥。
2. 至少记录一次“错误现象 → 排查动作 → 最终结论”；即使未解决，也记录已验证的事实。
3. 提交一个 PR（初期不会 PR 可以先提交个人分支并报告链接），标题格式：`W14 学员昵称 - 任务主题`。
4. PR 描述复制 [提交模板](../../templates/SUBMISSION_TEMPLATE.md)，不得只上传截图而没有源码。

## 验收清单（主力抽查）

- [ ] 不凭主观印象直接给方向定生死
- [ ] 每个方向有人知晓其接口
- [ ] 后续计划有可验证的单项成果

### 口头/录屏追问（任选 1～2 题）

1. 未来你能独立承担的最小任务是什么？
2. 如果主力请假一周，你会如何继续推进？

## 如果做不出来怎么办？

- 先完成能工作的最小版本，不要为了选做任务耗光 7 小时。
- 超过 30 分钟仍卡住，按 [求助模板](../../templates/HELP_TEMPLATE.md) 记录现象、尝试和日志，发 GitHub Issue / 群里求助。
- 截止前主动说明卡点可申请一次补交；**未完成但有真实排错记录**，与无说明不提交区别评价。
- 本周属于培训计划，不需要实车联调或新模型训练。

## W14 三选一试探题（3 小时以内）

- **大符/运动目标**：从原地旋转视频每隔约 0.5 秒抽一帧，标记装甲板可见性，写出对旋转目标检测最困难的两个现象；选做可视化质心轨迹（不要求预测算法）。
- **识别模型/数据**：制作 30 张图像样例，定义统一标注字段与标注约束，记录模糊、遮挡、曝光问题；不要求训练 YOLO。
- **EKF/Tracker/集成**：在现有离线脚本中可视化逐帧目标位置，统计无效点与异常跳变，解释为什么滤波前需要可靠测量；不要求手写 EKF。

三名主力对不同方向题目统一使用“能复现、能讲明白、能发现问题”的标准。
