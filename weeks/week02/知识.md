# W02 知识文档：systemd 开机自启 + 线性代数 + C++ 摸底

> 对象：四名大一自瞄新人｜每周约 7 小时｜**先理解用途，再跟着示例实践，最后独立完成任务**。

## 本周到底在做什么？

会管理一个系统服务，并能用 C++ 程序表达二维线性变换。

## 为什么要学？它在 RoboMaster 自瞄中有什么用？

NUC 上自瞄程序可能需要随系统启动、异常重启和写日志；线代是相机/云台坐标变换、PnP 和 EKF 的共同基础。本周不是为了学完数学，而是建立几何直觉。

## 你需要建立的基础认识

1. systemd 是 Linux 服务管理体系；shell 脚本在终端执行不等于系统开机自启。
2. service 的 ExecStart、User、Restart、WantedBy 分别控制执行程序、用户、失败恢复和启用目标。
3. 向量可表示位置/方向；矩阵可以表示线性变换，旋转再平移写为 p’=Rp+t。
4. 3Blue1Brown 视频建立直觉，数学理解必须落实到手算和代码。

## 推荐学习顺序（不要求死记全部 API）

1. 先阅读 `知识01_systemd服务.md`，用给出的安全示例程序完成系统级服务创建、启动、查看日志、启用及重启验证。
2. 阅读 `知识02_线性代数与坐标变换.md` 并观看官方视频 01～04，不要求刷完全集。
3. 独立实现 `transform(x,y,degree,tx,ty)`，读取输入后输出结果；用至少三组数据验证。
4. 按 `任务.md` 清单提交源码、命令证据、录屏或截图及“我遇到的一个问题”。

## 常见错误与提醒

- 只复制教程里的命令/代码而不记录“输入是什么、输出是什么、为什么成功”，不能算真正掌握。
- 任何相机尺寸、角点次序、坐标系、规则版本等关键假设，必须写明来源或标注“教学假设”。
- 遇到和文档不同的环境、版本或数据，不要硬套结果；先保存日志和最小复现步骤。
