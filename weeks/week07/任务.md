# W07 每周任务：PnP 入门：先从合成数据求位姿

- **日期**：2026-12-21 ～ 2026-12-27
- **截止**：2026-12-27（周日）23:59，中国标准时间 UTC+8
- **投入预算**：7 小时/人；阅读 2h／实现 3h／测试 1h／提交 1h
- **完成形式**：四人各自独立完成；允许查文档和使用 AI，但必须能解释自己的代码。
- **先读**：[知识.md](知识.md)；W02 另有专题知识文档。

## 本周要达成什么能力？

在已知内参与角点对应关系的条件下运行 solvePnP 并验证重投影。

## 完成路径（按顺序做）

1. 按 W6 的四点模型（尺寸采用“教学假设值”，明确不是比赛官方尺寸）生成合成像素点。
2. 调用 `cv::solvePnP` 估计 rvec/tvec。
3. 调用 `cv::projectPoints` 计算平均重投影误差。
4. 改变 Z 距离和角点噪声，观察解算结果变化。

## 基础必做（以可复现为准）

- [ ] 合成数据 + 内参参数说明
- [ ] 位姿求解程序、输出及重投影误差
- [ ] 说明坐标系和单位

## 选做挑战（不作为留队硬门槛）

- 比较两种 PnP flags 的求解结果
- 用噪声模拟检测角点偏差

## 交付方式与证据

1. 在本人分支或个人提交目录中上传源码、CMakeLists、README 与测试记录；不要上传 `build/`、系统文件、未授权比赛视频、设备密钥。
2. 至少记录一次“错误现象 → 排查动作 → 最终结论”；即使未解决，也记录已验证的事实。
3. 提交一个 PR（初期不会 PR 可以先提交个人分支并报告链接），标题格式：`W07 学员昵称 - 任务主题`。
4. PR 描述复制 [提交模板](../../templates/SUBMISSION_TEMPLATE.md)，不得只上传截图而没有源码。
