# W07 知识文档：PnP 入门：先从合成数据求位姿

> 对象：四名大一自瞄新人｜每周约 7 小时｜**先理解用途，再跟着示例实践，最后独立完成任务**。

## 本周到底在做什么？

在已知内参与角点对应关系的条件下运行 solvePnP 并验证重投影。

## 为什么要学？它在 RoboMaster 自瞄中有什么用？

先用已知正确答案的数据排除“标定不匹配”“角点不准”的干扰，才能理解 Solver 具体做了什么。

## 你需要建立的基础认识

1. PnP 根据已知 3D 物体点和 2D 图像点对应关系，估计物体到相机的变换。
2. `solvePnP` 典型输出 rvec 和 tvec，tvec 不是云台相对目标位置。
3. 使用 `projectPoints` 重投影，比较投影点与输入点的像素差异。
4. 平面四点解可能有歧义，尤其 IPPE 类方法存在多解；先掌握接口与验证，不以唯一最优角度为高难考核。

## 推荐学习顺序（不要求死记全部 API）

1. 按 W6 的四点模型（尺寸采用“教学假设值”，明确不是比赛官方尺寸）生成合成像素点。
2. 调用 `cv::solvePnP` 估计 rvec/tvec。
3. 调用 `cv::projectPoints` 计算平均重投影误差。
4. 改变 Z 距离和角点噪声，观察解算结果变化。

## 常见错误与提醒

- 只复制教程里的命令/代码而不记录“输入是什么、输出是什么、为什么成功”，不能算真正掌握。
- 任何相机尺寸、角点次序、坐标系、规则版本等关键假设，必须写明来源或标注“教学假设”。
- 遇到和文档不同的环境、版本或数据，不要硬套结果；先保存日志和最小复现步骤。
