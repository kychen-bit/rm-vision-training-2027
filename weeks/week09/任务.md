# W09 每周任务：MiniAutoAim 集成与视频可视化

- **日期**：2027-01-04 ～ 2027-01-10
- **截止**：2027-01-10（周日）23:59，中国标准时间 UTC+8
- **投入预算**：7 小时/人；集成 4h／调试 2h／提交 1h
- **完成形式**：四人各自独立完成；允许查文档和使用 AI，但必须能解释自己的代码。
- **先读**：[知识.md](知识.md)；W02 另有专题知识文档。

## 本周要达成什么能力？

一条命令处理视频，展示输入、角点、位姿或状态提示。

## 完成路径（按顺序做）

1. 将 W4 VideoReader、W8 角点读取、W7 Solver 放入同一个 CMake 项目。
2. 支持命令行 `--video` 和 `--corners`，在无目标帧显示明确提示。
3. 处理静止与原地旋转两段视频，保存运行录屏。
4. README 给出新电脑从零复现的命令。

## 基础必做（以可复现为准）

- [ ] 单仓库可运行 MiniAutoAim
- [ ] 两段视频运行记录
- [ ] 无目标帧的稳定行为
- [ ] README 与模块流程图

## 选做挑战（不作为留队硬门槛）

- 支持 W5 自动候选结果连接到管线（可保留手动回退）
- 保存每帧 CSV 结果

## 交付方式与证据

1. 在本人分支或个人提交目录中上传源码、CMakeLists、README 与测试记录；不要上传 `build/`、系统文件、未授权比赛视频、设备密钥。
2. 至少记录一次“错误现象 → 排查动作 → 最终结论”；即使未解决，也记录已验证的事实。
3. 提交一个 PR（初期不会 PR 可以先提交个人分支并报告链接），标题格式：`W09 学员昵称 - 任务主题`。
4. PR 描述复制 [提交模板](../../templates/SUBMISSION_TEMPLATE.md)，不得只上传截图而没有源码。

## 验收清单（主力抽查）

- [ ] 不需要手改绝对路径
- [ ] 原地旋转失败帧可解释
- [ ] 能够追踪一帧数据流

### 口头/录屏追问（任选 1～2 题）

1. 某帧突然跳到错误位置，最先排查哪些模块？
2. 为什么连续输出三维坐标不代表已经实现目标跟踪？

## 如果做不出来怎么办？

- 先完成能工作的最小版本，不要为了选做任务耗光 7 小时。
- 超过 30 分钟仍卡住，按 [求助模板](../../templates/HELP_TEMPLATE.md) 记录现象、尝试和日志，发 GitHub Issue / 群里求助。
- 截止前主动说明卡点可申请一次补交；**未完成但有真实排错记录**，与无说明不提交区别评价。
- 本周属于培训计划，不需要实车联调或新模型训练。
