# W09 知识文档：MiniAutoAim 集成与视频可视化

> 对象：四名大一自瞄新人｜每周约 7 小时｜**先理解用途，再跟着示例实践，最后独立完成任务**。

## 本周到底在做什么？

一条命令处理视频，展示输入、角点、位姿或状态提示。

## 为什么要学？它在 RoboMaster 自瞄中有什么用？

自瞄研发是完整数据链路；任何一阶段错误都需要能在可视化与日志中观察到。

## 你需要建立的基础认识

1. 数据流应区分图像采集/读取、检测或角点输入、位姿解算、显示输出。
2. 处理耗时是本机处理时间，不等同于机器人闭环延迟。
3. 日志内容应标记输入来源、帧号、有效目标状态、错误原因。
4. 原地旋转视频用来观察角点可见性和位姿连续性，但不等于 EKF 或反小陀螺能力。

## 推荐学习顺序（不要求死记全部 API）

1. 将 W4 VideoReader、W8 角点读取、W7 Solver 放入同一个 CMake 项目。
2. 支持命令行 `--video` 和 `--corners`，在无目标帧显示明确提示。
3. 处理静止与原地旋转两段视频，保存运行录屏。
4. README 给出新电脑从零复现的命令。

## 常见错误与提醒

- 只复制教程里的命令/代码而不记录“输入是什么、输出是什么、为什么成功”，不能算真正掌握。
- 任何相机尺寸、角点次序、坐标系、规则版本等关键假设，必须写明来源或标注“教学假设”。
- 遇到和文档不同的环境、版本或数据，不要硬套结果；先保存日志和最小复现步骤。
