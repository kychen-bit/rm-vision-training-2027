# W13 知识文档：真实仓库中的第一次安全改动

> 对象：四名大一自瞄新人｜每周约 7 小时｜**先理解用途，再跟着示例实践，最后独立完成任务**。

## 本周到底在做什么？

完成一次低风险、可回滚、可证明的实际修改。

## 为什么要学？它在 RoboMaster 自瞄中有什么用？

新人从“会看代码”转向“能维护代码”，最重要的是懂得改动范围、如何验证和如何回滚。

## 你需要建立的基础认识

1. 优先修改日志、配置可读性、异常提示、离线可视化等安全模块。
2. 不要首个 PR 就重写 Tracker、预测模型或实车控制协议。
3. PR 描述应有动机、范围、验证方法与回退计划。
4. 代码修改可能影响已有功能，要有至少一个回归测试。

## 推荐学习顺序（不要求死记全部 API）

1. 从主力维护的“安全小任务列表”选 1 项，先复述预期行为。
2. 新建分支修改，并给出修改前后对比。
3. 用已有离线视频或测试命令验证正常与异常路径。
4. 提交 PR，修复审查意见并完成复盘。

## 常见错误与提醒

- 只复制教程里的命令/代码而不记录“输入是什么、输出是什么、为什么成功”，不能算真正掌握。
- 任何相机尺寸、角点次序、坐标系、规则版本等关键假设，必须写明来源或标注“教学假设”。
- 遇到和文档不同的环境、版本或数据，不要硬套结果；先保存日志和最小复现步骤。
