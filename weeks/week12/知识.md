# W12 知识文档：运行队内工程：编译、离线输入、观察日志

> 对象：四名大一自瞄新人｜每周约 7 小时｜**先理解用途，再跟着示例实践，最后独立完成任务**。

## 本周到底在做什么？

安全运行队内工程可离线部分，并写出完整复现步骤。

## 为什么要学？它在 RoboMaster 自瞄中有什么用？

真实工程会出现依赖、参数、DDS、视频文件路径等实际问题，知道源码结构不代表具备调试能力。

## 你需要建立的基础认识

1. colcon 工作空间可能存在 underlay/overlay 覆盖关系；需要清楚 source 哪个环境。
2. 检查依赖版本与 ROS_DOMAIN_ID，不要为了运行临时大改原工程。
3. 离线运行优于直接操作实车发射、运动或自动控制。
4. 通过日志、topic 信息和可视化判断系统状态，保留复现命令。

## 推荐学习顺序（不要求死记全部 API）

1. 由主力提供一个固定版本、运行前置条件和允许操作范围。
2. 从干净 shell 编译或运行队内离线演示，记录遇到的错误及处理。
3. 使用 ros2 topic/日志观察模块输出（仅访问允许的测试环境）。
4. 给出“新电脑复现清单”，列出无法复现的条件。

## 常见错误与提醒

- 只复制教程里的命令/代码而不记录“输入是什么、输出是什么、为什么成功”，不能算真正掌握。
- 任何相机尺寸、角点次序、坐标系、规则版本等关键假设，必须写明来源或标注“教学假设”。
- 遇到和文档不同的环境、版本或数据，不要硬套结果；先保存日志和最小复现步骤。
