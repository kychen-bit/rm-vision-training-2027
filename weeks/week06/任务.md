# W06 每周任务：相机模型、像素坐标与四角点

- **日期**：2026-12-14 ～ 2026-12-20
- **截止**：2026-12-20（周日）23:59，中国标准时间 UTC+8
- **投入预算**：7 小时/人；理论 2h／标注 2h／编程 2h／提交 1h
- **完成形式**：四人各自独立完成；允许查文档和使用 AI，但必须能解释自己的代码。
- **先读**：[知识.md](知识.md)；W02 另有专题知识文档。

## 本周要达成什么能力？

理解从三维点到像素的投影，建立角点顺序及数据约定。

## 完成路径（按顺序做）

1. 手算给定 3D 点的针孔投影坐标。
2. 从视频中选取 5 张静止/旋转帧，手动标记装甲板四角点（若边界不可见则标为不可用）。
3. 为一个虚拟相机配置 K，写 C++ 函数将已知三维点投影到像素平面。
4. 核对已有内参视频与相机型号、分辨率、裁切、标定时间是否一致，填写状态。

## 基础必做（以可复现为准）

- [ ] 投影计算程序和测试
- [ ] 5 张帧及角点标注 CSV（允许不可用标记）
- [ ] 标定参数适配性检查表

## 选做挑战（不作为留队硬门槛）

- 比较两种焦距对投影结果的影响
- 增加图片叠加角点顺序的可视化

## 交付方式与证据

1. 在本人分支或个人提交目录中上传源码、CMakeLists、README 与测试记录；不要上传 `build/`、系统文件、未授权比赛视频、设备密钥。
2. 至少记录一次“错误现象 → 排查动作 → 最终结论”；即使未解决，也记录已验证的事实。
3. 提交一个 PR（初期不会 PR 可以先提交个人分支并报告链接），标题格式：`W06 学员昵称 - 任务主题`。
4. PR 描述复制 [提交模板](../../templates/SUBMISSION_TEMPLATE.md)，不得只上传截图而没有源码。
