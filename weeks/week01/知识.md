# W01 知识文档：入队环境与规则（已布置，补充复盘）

> 对象：四名大一自瞄新人｜每周约 7 小时｜**先理解用途，再跟着示例实践，最后独立完成任务**。

## 本周到底在做什么？

验证 Ubuntu 安装与 RoboMaster 自瞄基本任务认知，不以复杂代码为目标。

## 为什么要学？它在 RoboMaster 自瞄中有什么用？

自瞄不是单一算法。规则决定装甲板类型、几何约束和机器人动作边界；系统决定后续 C++ 工具链能否运行。

## 你需要建立的基础认识

1. Ubuntu 双系统与 WSL2 的区别：前者是真实 Linux 启动环境，后者运行于 Windows 的虚拟化环境；本队优先真实 Ubuntu。
2. 规则手册应明确哪一年/哪一版本；尺寸、角度、数量等不能依靠网上二手总结。
3. 自瞄基本链路：图像 → 检测 → 角点/类别 → 位姿 → 跟踪/预测 → 控制。

## 推荐学习顺序（不要求死记全部 API）

1. 检查 `lsb_release -a`、`g++ --version`、`git --version`，写下异常及解决过程。
2. 从队内指定的 2027 赛季规则手册抽取与装甲板、自瞄有关的条目，逐项注明章节与页码。
3. 画一张自瞄链路流程图，用自己的话说明每一阶段输入与输出。

## 常见错误与提醒

- 只复制教程里的命令/代码而不记录“输入是什么、输出是什么、为什么成功”，不能算真正掌握。
- 任何相机尺寸、角点次序、坐标系、规则版本等关键假设，必须写明来源或标注“教学假设”。
- 遇到和文档不同的环境、版本或数据，不要硬套结果；先保存日志和最小复现步骤。
