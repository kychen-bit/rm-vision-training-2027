# W08 每周任务：角点数据接口：把检测与 PnP 解耦

- **日期**：2026-12-28 ～ 2027-01-03
- **截止**：2027-01-03（周日）23:59，中国标准时间 UTC+8
- **投入预算**：7 小时/人；设计 1.5h／实现 3.5h／测试提交 2h
- **完成形式**：四人各自独立完成；允许查文档和使用 AI，但必须能解释自己的代码。
- **先读**：[知识.md](知识.md)；W02 另有专题知识文档。

## 本周要达成什么能力？

用手工角点/预先提供的角点 CSV 连接 Detector 与 Solver。

## 完成路径（按顺序做）

1. 定义 `ArmorObservation` 结构体（帧号、valid、四角点）。
2. 从 CSV 读取手工角点；缺失时在画面标记 no target 并跳过求解。
3. 调用 W7 Solver 输出位姿并叠加在图像上。
4. 至少测试 2 个无效输入，并记录行为。

## 基础必做（以可复现为准）

- [ ] 角点 CSV 读取与数据检查
- [ ] 视频上叠加角点编号和 PnP 结果
- [ ] 2 类异常输入处理

## 选做挑战（不作为留队硬门槛）

- 将 W5 候选框中心转为人工辅助标注的初始提示
- 支持鼠标点选四角点

## 交付方式与证据

1. 在本人分支或个人提交目录中上传源码、CMakeLists、README 与测试记录；不要上传 `build/`、系统文件、未授权比赛视频、设备密钥。
2. 至少记录一次“错误现象 → 排查动作 → 最终结论”；即使未解决，也记录已验证的事实。
3. 提交一个 PR（初期不会 PR 可以先提交个人分支并报告链接），标题格式：`W08 学员昵称 - 任务主题`。
4. PR 描述复制 [提交模板](../../templates/SUBMISSION_TEMPLATE.md)，不得只上传截图而没有源码。

## 验收清单（主力抽查）

- [ ] 不存在角点时不崩溃
- [ ] 能解释 detector/solver 的接口边界
- [ ] 角点顺序一致

- 截止前主动说明卡点可申请一次补交；**未完成但有真实排错记录**，与无说明不提交区别评价。
- 本周属于培训计划，不需要实车联调或新模型训练。
