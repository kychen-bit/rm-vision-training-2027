# W11 知识文档：理解 ROS2 自瞄项目的数据流

> 对象：四名大一自瞄新人｜每周约 7 小时｜**先理解用途，再跟着示例实践，最后独立完成任务**。

## 本周到底在做什么？

读懂现有工程的模块职责和消息传递，不要求新人重写节点。

## 为什么要学？它在 RoboMaster 自瞄中有什么用？

真实自瞄不仅是检测和解算，还存在时间戳、坐标系、预测、弹道、控制与上下位机接口。

## 你需要建立的基础认识

1. ROS2 Node、Topic、Message、Callback 是模块间通信的基本概念。
2. Detector → Solver → Tracker/Predictor → 控制指令应结合本队真实代码，不硬套网上某一框架。
3. rclcpp 执行器、回调频率和 QoS 可能影响数据传输。
4. 注意真实自瞄发送下位机的控制数据定义，以本队代码为准，不擅自假设是角度偏差。

## 推荐学习顺序（不要求死记全部 API）

1. 按照队内提供的项目版本说明，从入口 main 与 launch 文件追踪 1 条数据流。
2. 画模块图，注明关键 topic、消息字段、坐标系与频率（未知请标未知）。
3. 运行 ROS2 demo talker/listener 或队内允许的离线节点。
4. 写下仍看不懂的 5 个代码位置与疑问。

## 常见错误与提醒

- 只复制教程里的命令/代码而不记录“输入是什么、输出是什么、为什么成功”，不能算真正掌握。
- 任何相机尺寸、角点次序、坐标系、规则版本等关键假设，必须写明来源或标注“教学假设”。
- 遇到和文档不同的环境、版本或数据，不要硬套结果；先保存日志和最小复现步骤。
